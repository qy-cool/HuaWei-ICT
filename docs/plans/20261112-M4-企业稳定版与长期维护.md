[返回总体规划](20261112-企业自托管AI软件工程平台总体规划.md)。本表为阶段交付基线，实际进度以版本和开发日志为准。

## 本轮实现进度

OIDC 固定主体映射、恢复到新控制面、工作流生成候选包和共享数据库归属已落地。企业真实身份源、正式签名发行、跨故障域高可用与升级窗口继续验收。 [实施与验证记录](../logs/20261112-企业平台实施与验证.md)

## 工作方式

区分中控恢复与业务恢复。离线业务继续服务，恢复的中控核对节点实际版本、执行代次和凭据后重新派发。

## 开发任务

- [ ] 支持企业 OIDC 单点登录，映射团队与项目角色，并保留可审计的管理员恢复路径。
- [ ] 增加节点排空、滚动升级、稳定版兼容窗口、任务配额和存储保留策略。
- [ ] 增加模型、Git、数据库和节点凭据轮换；验证撤权对运行中会话生效。
- [ ] 完成多实例中控的连接归属、调度租约、工作区路由和故障接管。
- [ ] 从干净机器恢复中控数据库、制品索引、对象、密钥材料和节点关联。恢复后先对账再开放新派发。
- [ ] 建立 GitHub Releases、amd64/arm64 安装包、签名与校验、升级说明、支持矩阵、贡献指南、漏洞报告渠道及维护者职责。

## 交付与交接

交付 OIDC、权限审计、凭据轮换、容量报告、升级/灾备手册、签名发行物、SBOM、支持矩阵和维护流程。

## 验收与异常场景

验证新装、上一稳定版升级、干净运行机恢复；在两个独立中控实例验证持有 WSS 的实例宕机后接管和旧会话失效。

验收记录包含版本、输入、复现步骤、预期和实际结果、恢复动作及环境清理情况。未实测的环境列入待验证项。
