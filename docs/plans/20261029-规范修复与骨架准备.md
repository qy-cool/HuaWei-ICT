## 骨架技术基线

| 层 | 基线 |
|---|---|
| 运行时 | Java 21；Maven Wrapper 3.9.x |
| 后端 | Spring Boot 4.1.2；MyBatis-Plus 3.5.18（`mybatis-plus-spring-boot4-starter`）；springdoc-openapi 3.2.0；Flyway；Jakarta Validation |
| 数据库 | 华为云 RDS MySQL 8.0；utf8mb4；Flyway 管 schema |
| 前端 | React 19、Vite、TS strict、Tailwind CSS v4、shadcn/ui（Base UI）、TanStack Router/Query/Form/Table、Zustand、axios、zod、ECharts、lucide-react、sonner |
| 测试 | JUnit 5 + Mockito（后端）；Vitest + jsdom + Testing Library（前端） |
| CI | `Verify Server`（Maven test）、`Verify Web`（typecheck/lint/test/build） |

前端具体版本在 `web/package.json` 与 `pnpm-lock.yaml` 中锁定；后端具体版本在
`server/pom.xml` 中锁定。二者与上表不一致时，先更新本计划与决策笔记。
