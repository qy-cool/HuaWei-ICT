# 华为云产品映射（赛事或展示材料）

2026-11-20。本文是[部署与基础设施选项](../tech-summary/deployment-options.md)在华为云方向上的材料映射，供需要说明「如何在华为云上部署或演示」时使用。

它**不是**架构约束，也不是日常开发的前置清单。平台默认与云厂商解耦；华为云是可选方案和当前试验环境。产品主线与优先级仍见[产品定位](../intro/product-positioning.md)和 A1–A5 队列。

状态按已有实测记录登记，未实测的一律标「未接入」。

## 1. 叙事口径

对外可以说：Cloide 是企业自托管的 AI 软件工程平台，也可以部署在华为云上做试验或演示。「自托管」指数据主权（代码、凭据、审计留在企业可控边界内）；「华为云」是可选运行环境与可选托管服务，两者不矛盾。不要写成「全部模型与基础设施必须使用华为云产品」。

## 2. 映射总表

| 平台层 | 仓库默认/自建组件 | 华为云上的对应产品（可选） | 接入状态 | 改造点 |
|---|---|---|---|---|
| 模型服务 | OpenAI 兼容端点（默认关闭）；Pi 可用回环或节点本地配置 | MaaS（ModelArts Studio 等） | 未接入真实端点（DevSpace 手册留有接入模板） | 将 `AI_BASE_URL` 指向 MaaS 的兼容端点；项目级网关见 B1，尚未交付 |
| 中控元数据库 | Compose 基线 MySQL 8.4；DevSpace 试验机实测 8.0.37 | RDS for MySQL | 未接入 | `DB_HOST` 等改指向 RDS；验证 Flyway 全量迁移与门控 IT |
| 缓存/多实例票据 | Compose 基线 Redis 7（默认关闭）；DevSpace 试验机曾为 Redis 4.0.14 | DCS for Redis | 未接入 | `REDIS_HOST` 指向 DCS；验证多实例 ticket 共享 |
| 消息队列 | Compose 基线 RabbitMQ 4.3；DevSpace 试验机曾为 3.9.10 | DMS for RabbitMQ | 未接入 | `spring.rabbitmq` 指向 DMS；验证 Outbox 投递与补发 |
| 制品/日志/SBOM 存储 | 中控本地持久目录 | OBS（S3 兼容 API） | 未接入 | 增加对象存储后端；数据库只存引用与摘要 |
| 计算/节点 | 企业 Linux 主机或虚拟机 | ECS / DevSpace | **已接入**（DevSpace，openEuler 22.03 aarch64） | 展示用截图可归档；版本差见部署选项第 3.6 节 |
| 代码托管与协作 | GitHub App（回环协议已验证，真实安装待做） | CodeArts Repo/Pipeline 等 | 未接入 | 视实际需要决定，不做承诺 |

开发工具（例如华为云码道 CodeArts）是否构成某次赛题的技术要求，**以官方原文为准**。本仓库不把「必须使用某工具」或「已开源到某托管平台即满足条款」写成一般结论。若参赛需要过程留痕，材料可放在 `codearts-trace/`，但不作为日常开发前置条件。

## 3. 接入与验收

各项技术步骤、环境变量与回归入口以[部署与基础设施选项](../tech-summary/deployment-options.md)第 3 节为准，此处不重复成第二套手续。补充两点：

- 引用 DevSpace「已跑通」时，必须同时说明该次现场的 MySQL / Redis / RabbitMQ 版本与 Compose 基线不同。
- 控制面 3.31 秒是 2026-11-12、V50 范围的备份及恢复演练，不能写成当前 V53 的恢复指标。

## 4. 与赛程、优先级的关系

参赛日历（报名、初赛、决赛）只影响材料准备，不重排 A1–A5，不为「报名前必须完成某云产品接入」另行制定产品承诺。若团队决定参赛，再根据当时的官方原文核对工具、开源托管和其他条款，并更新本表状态。
