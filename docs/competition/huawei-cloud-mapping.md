# 华为云产品映射（赛题对接基线）

2026-11-19。本文件回答赛题「基于华为云产品打造 AI 创新应用」的产品选型问题：
平台每一层用什么华为云产品承载、当前接入状态、改造点与验收证据要求。
状态按[实施与验证记录](../logs/20261112-企业平台实施与验证.md)口径登记，
未实测的一律标「未接入」，不把规划写作事实。

## 1. 定位口径

产品叙事统一为一句话：**部署在华为云上的企业自托管 AI 软件工程平台**。
「自托管」指企业数据主权（代码、凭据、审计留在企业可控边界内），「华为云」
指运行底座与模型服务全部使用华为云产品。两者不矛盾，材料里避免只提
「私有化部署」让评委误以为与云无关。

## 2. 产品映射总表

| 平台层 | 自建/开源组件（现状） | 华为云目标产品 | 接入状态 | 改造点 |
|---|---|---|---|---|
| 开发工具链 | ZCode 等 AI 编码协作工具（`AGENTS.md` 协作规范） | **码道 CodeArts 代码智能体** | 未接入（待执行最小合规动作） | 团队安装码道（IDE/插件/CLI 任一形态），完成本仓库至少一次真实开发提交并留痕到 `codearts-trace/` |
| 模型服务 | OpenAI 兼容端点（`.env` 的 `AI_BASE_URL`，默认关闭）；Pi 编码任务回环模型 | **MaaS**（ModelArts Studio，盘古/DeepSeek 系列） | 未接入（仅 DevSpace 手册留有接入模板） | 填 `AI_BASE_URL` 指向 MaaS 的 OpenAI 兼容端点；按项目级凭据接入 B1 模型网关 |
| 中控元数据库 | 自建 MySQL（Docker compose 8.4；DevSpace 盒子实测 8.0.37，低于目标基线） | **RDS for MySQL** | 未接入 | `DB_HOST` 等连接串改指向 RDS；验证 Flyway V1–V53 全量迁移与 IT 门控回归 |
| 缓存/多实例票据 | 自建 Redis 7（默认关闭） | **DCS for Redis** | 未接入 | `REDIS_HOST` 改指向 DCS；验证多实例 ticket 共享路径 |
| 消息队列 | 自建 RabbitMQ 4.3 | **DMS for RabbitMQ**（可选） | 未接入 | `spring.rabbitmq` 地址改指向 DMS；验证 Outbox 投递与补发 |
| 制品/日志/SBOM 存储 | 中控本地持久目录（受鉴权 HTTPS） | **OBS**（S3 兼容 API） | 未接入 | 制品存储抽象增加 OBS 后端；数据库仅存对象引用与摘要 |
| 计算/节点 | 华为云 DevSpace（openEuler 22.03 aarch64，已实测部署全套） | **ECS / DevSpace** | **已接入**（DevSpace） | 补控制台截图与部署留痕归档到 `codearts-trace/` |
| 云上协作（可选加分） | GitHub App 集成（仓库托管在 GitHub） | **CodeArts Repo/Pipeline**（可选双通道） | 未接入 | 视赛程余量决定，不做承诺 |

> 码道 CodeArts 是赛题一的**强制技术要求**——官方技术要求原文为「下载并
> 使用华为云码道 CodeArts 代码智能体进行开发；基于已有智能体和 Skills，
> 关联 RDS、Redis 等华为云服务的快速开通并创建；完成应用作品在华为云上
> 的快速部署」。因此码道留痕优先级最高，RDS、Redis（DCS）为官方点名的
> 关联服务；DMS 与 CodeArts Repo/Pipeline 才是可选加分项：先完成码道 +
> MaaS + RDS + DCS，再视时间推进 OBS 与其余，材料中如实标注状态。

## 3. 每项产品的接入与验收要求

通用红线：所有接入均不得把 AK/SK 写入仓库；连接信息走环境变量，示例统一
`SERVER_IP_OR_DOMAIN`；每项接入完成后在 `docs/logs/` 落一条实测记录
（版本、实例规格、连接方式、回归结果、清理情况），并回填本表状态。

### 3.1 码道 CodeArts（开发工具链）——合规优先级最高

- 作用：满足赛题一「使用码道进行开发」的强制技术要求；官方同时要求
  「基于已有智能体和 Skills，关联 RDS、Redis 等华为云服务」。
- 接入方式：团队按官方指引安装码道（IDE / VS Code、IntelliJ 插件 /
  CLI 任一形态，体验版免费），接入团队惯用的模型端点。
- 验收：用码道完成本仓库至少一次真实开发提交（修文档或小改动即可），
  过程截图（工具界面 + 关联的提交）归档到 `codearts-trace/`；后续日常
  开发尽量在码道中进行，形成持续留痕。

### 3.2 MaaS（模型服务）

- 作用：AI 编码任务（Pi Worker）与运维 AI 问答的推理后端。
- 接入方式：`.env` 填 `AI_ENABLED=true`、`AI_BASE_URL`（MaaS OpenAI 兼容
  端点）、`AI_API_KEY`、`AI_MODEL`；凭据只在部署环境注入。
- 验收：编码任务端到端验收脚本（[20261112-编码任务端到端验收](../logs/20261112-编码任务端到端验收.md)）
  在 MaaS 端点上复跑一次，记录模型名、token 用量、任务结果；
  运维问答（`AI_QA_ENABLED`）同样实测一轮。
- 后续：按[总体规划](../plans/20261112-企业自托管AI软件工程平台总体规划.md)
  B1 工作包演进为项目级模型网关（按项目配凭据、预算、超时）。

### 3.3 RDS for MySQL（中控元数据库）

- 作用：替换自建 MySQL，承载平台全部元数据（Flyway V1–V53）。
- 接入方式：创建 RDS 实例（MySQL 8.0+），`DB_HOST/DB_NAME/DB_USER` 指向
  该实例，开启 SSL 按需设置 `DB_USE_SSL`。
- 验收：空库执行 Flyway 全量迁移；运行
  `RepositorySourceIdentityMySqlValidationIT`（`RUN_MYSQL_VALIDATION_TESTS` 门控）
  确认方言行为；跑 `./mvnw test` 一轮。

### 3.4 DCS for Redis（缓存与多实例票据）

- 作用：替换自建 Redis，用于多实例中控的 ticket 共享（`REDIS_ENABLED=true`）。
- 验收：两实例中控共享 DCS，验证 ticket 跨实例可用；单实例场景回归不受影响。

### 3.5 OBS（制品与日志存储）

- 作用：制品、构建日志、SBOM 从中控本地目录迁移到 OBS，支撑多实例共享。
- 接入方式：OBS 提供 S3 兼容 API，制品存储层增加 S3 后端配置项；
  数据库仅保存对象引用、摘要、大小、来源与校验状态（与总体规划 3.4 节一致）。
- 验收：签名制品上传/下载/摘要校验在 OBS 后端复跑
  [签名静态制品发布双机验收](../logs/20261112-签名静态制品发布双机验收.md)。

### 3.6 DMS for RabbitMQ（可选）

- 作用：替换自建 RabbitMQ，承载 Outbox 事件投递。
- 验收：消息队列恢复后由数据库扫描补调遗漏任务（见总体规划 6.1 节），
  在 DMS 上复演一次。

## 4. 与赛程的衔接

优先级：码道留痕（报名前）→ MaaS + RDS + DCS（初赛前）→ OBS / DMS
（视余量）。RDS 与 Redis 是赛题一点名的关联服务，MaaS 是 AI 应用推理
核心，三者与码道共同构成合规与演示的最小闭环。

- 报名截止（2026-11-30）前：完成码道安装与首次开发留痕
  （`codearts-trace/`）；本表作为「华为云产品选型理由」素材进入初赛
  材料；DevSpace 部署已有实测记录。
- 初赛（2026-12）前：完成 MaaS + RDS + DCS 三项接入与实测记录，OBS 视
  余量推进；更新本表状态列与 `docs/logs/` 证据链。
- 决赛前：控制台截图、连接配置（脱敏）、运行日志、故障注入记录归档到
  `codearts-trace/`，支撑现场复现。
- 开源合规：入围中国总决赛与全球总决赛的作品需开源至 Gitee、GitHub
  等社区；本仓库已托管 GitHub，保持公开与第三方许可材料完整即可满足。
