# 方案背景与价值（赛事材料映射）

2026-11-20。本文不是产品定位的主拷贝，只说明如何把已有事实适配到赛事或展示模板。

**请先阅读并引用**[产品定位与价值](../intro/product-positioning.md)。痛点（不可控 / 不可信 / 数据不出域）、方案定位、用户价值与已实测证据都以那一篇为准，避免在本目录再写一套可能过时的数字。

## 1. 映射时要守住的边界

- 产品目标是长期维护的企业级自托管平台，不是「为某道赛题定制的作品」。
- 华为云是可选部署/集成方案和当前试验环境。材料里可以说明为何在华为云上演示，但不要写成「模型与基础设施全部必须使用华为云产品」。
- 未接入的能力（例如真实 MaaS 端点、项目级模型网关、管理台页面）保持「未完成 / 未接入」，不要用现在时写成企业已经获得的能力。
- 引用 3.31 秒等数字时，必须带上原记录的范围：那是 2026-11-12 在 V1–V50、独立 MySQL 8.4.9 上的**备份及恢复**演练，不是当前 V53 的单独恢复时间。详见产品定位第 6 节。

## 2. 面向赛题时可以使用的一句话

若某次赛题要求「基于某云产品打造 AI 应用」，建议的表述是：

> Cloide 是企业自托管的 AI 软件工程平台，可部署在企业选定的环境中（当前试验环境包括华为云 DevSpace）。平台与云厂商、模型提供商解耦；在华为云上演示时，按需映射到 MaaS、RDS、DCS 等产品，映射表见[华为云映射](huawei-cloud-mapping.md)。

具体评分点和强制条款以官方原文为准，本文不作权威结论。
