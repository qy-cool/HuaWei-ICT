# 赛事材料适配（docs/competition/）

本目录用于**可选的阶段性展示或赛事材料适配**，不是产品主线，也不构成日常开发的前置条件。

Cloide 的目标是做成完整、可长期维护的企业级自托管 AI 软件工程平台。架构、路线图和近期优先级以[总体规划](../plans/20261112-企业自托管AI软件工程平台总体规划.md)与[现状盘点](../plans/20261112-现状盘点与下一轮开发计划.md)中的 A1–A5 为准，不因赛程、评分点或某次参赛要求压缩或绑死。

通用事实请直接使用：

- 产品定位与价值：[docs/intro/product-positioning.md](../intro/product-positioning.md)
- 创新性与证据：[docs/tech-summary/innovation.md](../tech-summary/innovation.md)
- 部署与基础设施选项（含华为云作为可选方案）：[docs/tech-summary/deployment-options.md](../tech-summary/deployment-options.md)

本目录只做「如何把已有事实映射到某次赛事或展示模板」。涉及工具强制、开源托管平台、报名截止等条款时，**以官方原文为准**；仓库内的转述不能当成已经核对或已经满足的结论。

## 初赛五要素（材料清单，不是产品范围）

若参加需要按官方模板准备下列要素，在此跟踪素材状态。写作时以官方模板为准；数字必须有复现依据，并与产品文档保持同一口径。

| 要素 | 要沉淀什么 | 建议位置 | 当前状态 |
|---|---|---|---|
| 方案背景与价值 | 赛题理解、业务痛点、方案定位、用户价值、云产品选型理由 | 先引用产品定位，再在本目录做赛事映射 | [初稿](方案背景与价值.md)（2026-11-20 起改为引用产品主线） |
| 创新性解读 | 与已有方案的差异、可验证的创新证据 | 先引用创新性文档，再按模板摘录 | [初稿](innovation.md)（2026-11-20 起改为引用产品主线） |
| 数据集选取与处理 | 数据来源与授权、规模、清洗与标注流程、评测集划分 | `docs/competition/` + `docs/logs/` | [提案稿](数据集与评测设计.md)（2026-11-26，待队长评审确认后才成为成文方案；数据全部自建合成，无外部授权问题） |
| 关键代码片段解读 | 架构承重代码、云接入、AI 链路、关键算法的讲解素材 | `docs/competition/` + 代码注释 | [初稿](关键代码解读.md)（2026-11-26，四段承重代码带行号与验收链接） |
| 可量化效果 | 准确率、时延、吞吐、效率提升等，附可复现的评测记录 | `docs/logs/` + `docs/competition/` | [初稿](可量化效果.md)（2026-11-26，已实测数字引用产品定位第 6 节；AI 指标口径已定义，数值待真实模型端点接入后采集） |

## 开工前置确认（2026-10-29）

以下由队长在写第一个业务接口/页面前确认；未确认前只允许搭骨架与跑通运行环境。这是产品开工清单，不是参赛门禁：

- [ ] 场景与目标用户
- [ ] MVP 3–5 个功能及优先级
- [ ] 数据来源、授权与评测集
- [ ] 可量化效果指标与采集方式
- [ ] 部署与基础设施选项（默认自托管；华为云等为可选项，见[部署选项](../tech-summary/deployment-options.md)）
- [ ] 报名状态与赛题方向（仅在决定参赛时确认；具体规则以官方原文为准）

若某次赛题对开发工具或过程留痕有要求，把过程材料放在 `codearts-trace/`，并在参赛材料中按官方原文说明；**不作为一般开发的前置约束**。

## 目录约定

- 设计系统：`design-system.md`（视觉唯一事实源，页面开工前确认）。
- 赛事中的华为云映射：`huawei-cloud-mapping.md`（只做可选方案的材料映射，状态随实测更新）。
- 若某次赛事要求过程留痕：`codearts-trace/`。
- 报名表与官方模板：本目录根下，文件名 `YYYYMMDD-主题.md`。
- 开发过程记录：`docs/logs/`；数据与评测记录同时链回产品文档或本目录。

## 红线

- 不含真实凭据、AK/SK、模型 Key、内网 IP；示例地址统一用 `SERVER_IP_OR_DOMAIN`。
- 量化效果只写可复现的评测结果；数据集必须说明来源与授权。
- 不把未接入的云服务或未完成的功能写成已交付。
- 现场复现所需的截图与数据必须能对应到可运行版本。
- 不擅自更改 MIT 许可，不删除实际存在的第三方许可义务。
