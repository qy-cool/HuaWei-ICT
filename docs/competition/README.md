# 比赛材料（docs/competition/）

本目录是初赛五要素素材与留痕的归档入口。素材在日常开发中随手沉淀，赛前只做
汇总与排版，不突击补写。

## 初赛五要素

| 要素 | 要沉淀什么 | 建议位置 | 当前状态 |
|---|---|---|---|
| 方案背景与价值 | 赛题理解、业务痛点、方案定位、用户价值、华为云产品选型理由 | `docs/competition/` 按主题建 md | 待补充 |
| 创新性解读 | 与已有方案的差异、技术或产品创新点、可验证的创新证据 | 同上 | 待补充 |
| 数据集选取与处理 | 数据来源与授权、规模、清洗与标注流程、评测集划分 | `docs/competition/` + `docs/logs/` | 待补充 |
| 关键代码片段解读 | 架构承重代码、华为云接入、AI 链路、关键算法的讲解素材 | `docs/competition/` + 代码注释 | 待补充 |
| 可量化效果 | 准确率、时延、吞吐、效率提升等，附可复现的评测记录 | `docs/logs/` + `docs/competition/` | 待补充 |

写作时以官方模板为准；数字必须有复现依据，不写无依据的估计。

## 开工前置确认（2026-10-29）

以下由队长在写第一个业务接口/页面前确认；未确认前只允许搭骨架与跑通云资源：

- [ ] 场景与目标用户
- [ ] MVP 3–5 个功能及优先级
- [ ] 数据来源、授权与评测集
- [ ] 可量化效果指标与采集方式
- [ ] 华为云产品映射（RDS / Redis / MaaS / OBS）
- [ ] 报名状态与赛题方向

## 目录约定

- 设计系统：`design-system.md`（视觉唯一事实源，页面开工前确认）。
- CodeArts 留痕：`codearts-trace/`（若执行最小合规动作，过程留痕放这里）。
- 报名表与官方模板：本目录根下，文件名 `YYYYMMDD-主题.md`。
- 开发过程记录：`docs/logs/`；数据与评测记录同时链回本目录。

## 红线

- 不含真实凭据、AK/SK、MaaS Key、内网 IP；示例地址统一用
  `SERVER_IP_OR_DOMAIN`。
- 量化效果只写可复现的评测结果；数据集必须说明来源与授权。
- 决赛有现场复现环节，材料中的截图与数据必须能对应到可运行版本。
