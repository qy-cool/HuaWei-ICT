# 源码同步失败回执重放验证

2026-11-26。基线为 `preview` 的 `b77c384`。任务与验收条件见[开发计划](../plans/20261126-源码同步失败回执重放.md)。

## 故障与修复

Go 节点在安装失败时发送任务号、`failed` 和错误说明。Java 中控保存了第一次报告；确认在途中丢失，节点就会从账本原样重发。旧中控把回执中缺席的三个核验摘要与派发时登记的摘要比较，第二次处理返回 `resource conflict`，节点收不到确认。

中控现在在同一事务内锁定该节点的任务、核对结果并落库。同一失败回执重放时，用首次保存的错误说明前缀对账，再发确认。保留原先对完整摘要的处理，成功回执继续逐项核对提交、目录树和下载包。协议见[节点作业协议](../protocol/node-jobs-v1.md)。
