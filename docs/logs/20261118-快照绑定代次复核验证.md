# 快照绑定代次复核验证

2026-11-18，ycwsjc。对应[开发计划](../plans/20261118-快照绑定代次复核.md)和[快照接口](../openapi/openapi-repository.json)。

`SourceIdentityService` 在写快照的短事务中调用 `RepositoryService.lockActiveGeneration`，按项目、仓库、原绑定代次查找活动行并加锁。GitHub 查询在开启事务前完成。如果原绑定已经失效，接口返回 HTTP 404，业务码为 40400。

| 验证 | 实测结果 |
|---|---|
| `SourceIdentityTests#rebindWhileResolvingTreeDiscardsSnapshotAndAllowsRetry`，本地 GitHub HTTP 替身与 H2 | 旧实现返回了快照，回归断言失败。修复后的服务抛出 `RESOURCE_NOT_FOUND`（对应 HTTP 404），快照和请求账本均为零行。同一请求号重新解析得到第 2 代快照，再次发送返回同一条记录。 |
| Java 21，`server/` 下执行 `sh ./mvnw -B -ntp test` | 916 项通过，失败、错误、跳过均为 0。 |
| 隔离 MySQL 8.4.13，InnoDB，REPEATABLE READ，空库应用 V1–V51 | `RepositorySourceIdentityMySqlValidationIT` 6 项通过。新增用例通过两个独立连接验证了锁的生效与释放。写快照的事务持锁期间，另一事务立即取锁收到 MySQL 3572。前一事务提交后可以取得同一行锁。 |

复跑数据库用例时，在 `server/` 目录对隔离库执行以下命令。环境变量要求见[数据库测试约定](../../.agents/skills/hwict-tests/references/java-spring.md)。本轮临时实例已关闭并清理。

```sh
sh ./mvnw -B -ntp -Pmysql-validation -Dit.test=RepositorySourceIdentityMySqlValidationIT \
  test-compile failsafe:integration-test failsafe:verify
```
