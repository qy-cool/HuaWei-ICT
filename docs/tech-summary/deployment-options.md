# 部署与基础设施选项

2026-11-20。本文说明 Cloide 的运行底座如何按企业需求选择和替换，以及当前仓库里已经核对过的现状。华为云是**可选**的部署与集成方案，也是当前的试验环境之一，不是全部组件的唯一必须实现。

产品定位见[产品定位与价值](../intro/product-positioning.md)。若某次展示或赛事要求说明与华为云产品的对应关系，再看[赛事材料中的华为云映射](../competition/huawei-cloud-mapping.md)；那些要求不回写为日常开发的前置条件。

## 1. 原则

- **解耦**：模型、身份、对象存储、缓存、消息队列和计算节点都可以按企业现有条件替换，只要满足接口与验收。默认不把某一云厂商写进架构硬约束。
- **现状与规划分开**：未在目标环境实测的接入一律标「未接入」，不把规划写成已交付。
- **凭据不入库**：连接信息走环境变量，示例地址统一 `SERVER_IP_OR_DOMAIN`；AK/SK、API Key、密码和 Token 不得写入仓库。
- **版本要写清环境**：本地 Compose 基线与某次试验机上的已装版本可能不同，不能混写成「当前就是某版本」。

## 2. 选项总表

| 平台层 | 仓库默认/自建组件 | 可选托管或替换 | 当前状态 | 说明 |
|---|---|---|---|---|
| 模型服务 | OpenAI 兼容端点（`.env` 的 `AI_BASE_URL`，默认关闭）；Pi 编码任务可用回环或节点本地模型配置 | 任意兼容端点，包括但不限于华为云 MaaS | 未接入真实托管端点 | 填 `AI_ENABLED`、`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`；项目级网关（B1）尚未交付 |
| 中控元数据库 | 自建 MySQL。Docker Compose 基线为 8.4 | 兼容的 MySQL 8.0+ 服务，包括但不限于 RDS for MySQL | 本地/Compose 按 8.4 使用；华为云 DevSpace 试验机实测为 8.0.37（高于 8.0，低于 Compose 8.4 基线） | 连接串走 `DB_HOST` 等；验收需 Flyway 全量迁移与相应 IT |
| 缓存/多实例票据 | 自建 Redis。Compose 基线为 Redis 7，默认 `REDIS_ENABLED=false` | 兼容 Redis 服务，包括但不限于 DCS | 未接入托管实例。DevSpace 试验机曾部署 Redis 4.0.14，与 Compose 基线不同 | `REDIS_HOST` 指向目标实例后验证票据共享 |
| 消息队列 | 自建 RabbitMQ。Compose 基线为 4.3 | 兼容 RabbitMQ 服务，包括但不限于 DMS | 未接入托管实例。DevSpace 试验机曾部署 RabbitMQ 3.9.10，与 Compose 基线不同 | 验证 Outbox 投递与补发 |
| 制品/日志/SBOM 存储 | 中控本地持久目录（受鉴权 HTTPS） | S3 兼容对象存储，包括但不限于 OBS | 未接入对象存储后端 | 规划是数据库只存对象引用与摘要，见总体规划 3.4 节 |
| 计算/节点 | 企业提供的 Linux 主机或虚拟机；节点主动连接中控 | 任意满足网络与架构要求的计算环境；当前试验过华为云 DevSpace | **DevSpace 已实测部署全套**（openEuler 22.03 aarch64） | 补控制台截图等展示材料不影响产品功能本身 |
| 代码托管与协作 | 当前集成以 GitHub App 为主（协议层已用回环服务验证，真实企业安装待做） | 企业既有 Git 托管与流水线，按接口扩展 | 真实企业 GitHub 安装未验收 | 不把某一代码托管网站写成一般开发的前置约束 |

通用红线：每项接入完成后在 `docs/logs/` 落一条实测记录（版本、实例规格、连接方式、回归结果、清理情况），并回填本表状态。

## 3. 各项接入与验收要点

### 3.1 模型服务

- 作用：AI 编码任务（Pi Worker）与运维 AI 问答的推理后端。
- 接入方式：`.env` 填 `AI_ENABLED=true`、`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL`；凭据只在部署环境注入。
- 验收：编码任务端到端脚本在目标端点上复跑，记录模型名、用量与任务结果；运维问答（`AI_QA_ENABLED`）同样实测一轮。见[编码任务端到端验收](../logs/20261112-编码任务端到端验收.md)。
- 后续：按[总体规划](../plans/20261112-企业自托管AI软件工程平台总体规划.md) B1 工作包演进为项目级模型网关（按项目配凭据、预算、超时）。

### 3.2 中控元数据库

- 作用：承载平台全部元数据（当前 Flyway 至 V53）。
- 接入方式：目标实例需兼容 MySQL 8.0+；`DB_HOST/DB_NAME/DB_USER` 指向该实例，SSL 按需设置 `DB_USE_SSL`。仓库日常开发与 Compose 基线以 8.4 为准。
- 验收：空库执行 Flyway 全量迁移；按需运行 `RepositorySourceIdentityMySqlValidationIT` 等门控 IT，并跑 `./mvnw test`。

### 3.3 缓存与多实例票据

- 作用：多实例中控的 ticket 共享（`REDIS_ENABLED=true`）。
- 验收：两实例中控共享同一 Redis，验证 ticket 跨实例可用；单实例场景回归不受影响。

### 3.4 对象存储

- 作用：制品、构建日志、SBOM 从中控本地目录迁到对象存储，支撑多实例共享。
- 接入方式：增加 S3 兼容后端配置；数据库仅保存对象引用、摘要、大小、来源与校验状态（与总体规划 3.4 节一致）。
- 验收：签名制品上传/下载/摘要校验在对象存储后端复跑[签名静态制品发布双机验收](../logs/20261112-签名静态制品发布双机验收.md)。

### 3.5 消息队列

- 作用：承载 Outbox 事件投递。
- 验收：消息队列恢复后由数据库扫描补调遗漏任务（见总体规划 6.1 节），在目标实例上复演一次。

### 3.6 当前试验环境（华为云 DevSpace）

2026-11-09 曾在华为云 DevSpace 盒子（openEuler 22.03 aarch64）部署过完整中控与依赖，记录见[华为云 DevSpace 部署](../logs/20261109-华为云DevSpace部署.md)。该次现场中间件版本为 MySQL 8.0.37、RabbitMQ 3.9.10、Redis 4.0.14，与仓库 Docker Compose 基线（MySQL 8.4、RabbitMQ 4.3、Redis 7）不同。引用「已在华为云跑通」时，应同时写明这一版本差，避免把试验机现状写成仓库默认基线。

## 4. 与开发优先级的关系

替换或接入某一云服务，是企业部署选项，不是重排产品路线的理由。当前开发仍按 A1–A5 推进；B1 模型网关、真实企业端点验收等按原队列排期，不为展示材料提前承诺日期。
